# Java Course

A collection of Java coursework completed through school over ten weeks. This repository demonstrates progression from Java fundamentals through object-oriented programming, exception handling, collections, and file processing.

## Course Topics

| Week | Topics |
|---|---|
| 01 | Java setup, syntax, procedural and object-oriented approaches |
| 02 | Data types, operators, type conversion, and input |
| 03 | Boolean expressions, conditionals, switches, and ternary operators |
| 04 | `for`, `while`, and `do-while` loops |
| 05 | Arrays, multidimensional arrays, and `ArrayList` |
| 06 | Classes, objects, constructors, and encapsulation |
| 07 | Inheritance, composition, and method overriding |
| 08 | Abstract classes, polymorphism, and casting |
| 09 | Interfaces, exceptions, and banking examples |
| 10 | Collections, CSV/text files, and data processing |

## Prerequisites

- JDK 11 or newer
- A Java IDE such as IntelliJ IDEA, Eclipse, or VS Code
- A terminal for compiling and running programs

## Running an Example

Each Java file can usually be compiled and run independently.

```bash
cd week01
javac HelloWorld.java
java HelloWorld
```

Because some examples depend on files from the same folder, run them from their week directory:

```bash
cd week10
javac DataProcessor.java
java DataProcessor
```
